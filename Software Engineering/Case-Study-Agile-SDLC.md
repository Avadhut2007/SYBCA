# Case-Study-Agile-SDLC

## Case Study: Online Food Delivery System using Agile Methodology and Software Requirements

Case Study Title:
Development of an Online Food Delivery System using Agile Scrum
Scenario
A startup company, QuickBite, wants to develop an Online Food Delivery System that enables customers to order food from nearby restaurants through a mobile app and website. Initially, the company planned a traditional development approach, but customer requirements changed frequently. Therefore, the company adopted the Agile Scrum methodology to deliver the software incrementally and gather continuous customer feedback.

## Problem Statement

QuickBite requires a software system with the following features:

- Customer Registration and Login
- Restaurant Search
- Food Menu Display
- Cart Management
- Online Payment
- Order Tracking
- Customer Reviews
- Restaurant Dashboard
- Admin Dashboard

The client wants the first version within 2 months and additional features later.

## Step 1: Requirement Gathering

The Business Analyst conducts interviews with customers, restaurant owners, and delivery partners.

## Functional Requirements

1. User Registration and Login
2. Search Restaurants
3. Browse Food Menu
4. Add Items to Cart
5. Online Payment
6. Track Orders
7. Order History
8. Restaurant Management
9. Admin Management
10. Customer Feedback

## Non-Functional Requirements

- Response time < 3 seconds
- System availability: 99.5%
- Secure online payment
- Easy-to-use interface
- Scalable architecture
- Mobile-friendly application
