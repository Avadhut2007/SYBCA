# SYBCA

This repository contains organized study notes and learning material for the SYBCA (Bachelor of Computer Applications) curriculum.

## Purpose
The notes have been cleaned and grouped into a dedicated folder for each subject so the content is easier to navigate and maintain.

## Subjects
- Computer Networks
- DSA in C
- Introduction To Python
- Linear Algebra
- Software Engineering
